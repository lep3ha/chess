# Chess Game

Учебный прототип шахматной доски на C++ и SFML: начальная расстановка фигур,
изменение размеров окна и вывод координат клетки при клике. Полная игра
и перемещение фигур через интерфейс не реализованы.

## Структура

```text
src/                 # Заголовки .hpp и реализации .cpp лежат рядом
├── app/             # Окно и цикл приложения
├── board/           # Доска, клетки, модель позиции и геометрия
├── graphics/        # Графические компоненты и загрузка ресурсов
├── pieces/          # Фигуры и описание ходов
├── Config.hpp       # Общие константы и типы
└── main.cpp         # Точка входа
assets/              # Изображения и тема оформления
tests/              # Тесты и вспомогательные заголовки
docs/               # Зависимости, сборка и запуск по платформам
CMakeLists.txt      # Конфигурация сборки
.github/workflows/  # Автоматическая сборка и тесты
```

Инструкции: [Ubuntu](docs/ubuntu.md) · [Windows](docs/windows.md) · [macOS](docs/macos.md).
