# Chess (C++ / SFML)

Коротко
-
Простой шахматный проект на C++ с использованием библиотеки SFML для графики и ввода. В проект включены исходники, ресурсы и скрипт сборки.

Требования
-
- macOS (тестировалось на recent macOS)
- C++17 совместимый компилятор (clang / gcc)
- CMake (если будете собирать вручную)
- SFML (рекомендуемая версия: 2.5 или новее)

Установка зависимостей (macOS)
-
Установите SFML через Homebrew:

```sh
brew install sfml
```

Сборка
-
В корне проекта есть скрипт сборки `build.sh` — он пытается собрать проект через CMake. Запустите:

```sh
./build.sh
```

Если хотите вручную через CMake:

```sh
mkdir -p build && cd build
cmake ..
cmake --build . --config Release
```

Запуск
-
После успешной сборки исполняемый файл окажется в `bin/ChessGame` (или `build/bin/` в зависимости от скрипта). Запустите:

```sh
./bin/ChessGame
```

Структура проекта
-
- `include/` — заголовочные файлы проекта
- `source/` — исходники
- `assets/` — графика, темы и прочие ресурсы
- `ExternalLibraries/SFML/` — включённые заголовки/пакеты SFML (в репозитории)
- `bin/` — скомпилированный бинарник (обычно игнорируется в .gitignore)

Ресурсы
-
Темы изображений находятся в `assets/images/themes/`.
